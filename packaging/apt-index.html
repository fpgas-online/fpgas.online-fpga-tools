fpgas.online FPGA tools

Debian packages of openFPGALoader and OpenOCD carrying the fpgas.online patch series: Raspberry Pi 5 RP1 PIO JTAG, Kosagi NeTV2 configurations, the Tiny Tapeout FPGA Demo Board, SPI flash identification and Device DNA / ECP5 TraceID reads. One flat repository per suite; arm64 and armhf.

Packages

PackageTrackContents
openfpgaloader-fpgasonlinestablelatest openFPGALoader release + patches
openfpgaloader-fpgasonline-gitmasteropenFPGALoader git master + patches
openocd-fpgasonlinestablelatest OpenOCD release + patches
openocd-fpgasonline-gitmasterOpenOCD git master + patches

Each package replaces Debian's openfpgaloader / openocd (and the older *-rp1pio packages) in place. Versions read <upstream>+fpgasonline.<patchset>, e.g. 1.1.1+fpgasonline.0.0.post12, or <upstream>+git<date>.<sha>+fpgasonline.<patchset> for the git track.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://fpgas-online.github.io/fpgas.online-fpga-tools/fpgas-online-fpga-tools.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/fpgas-online-fpga-tools.gpg
echo "deb [signed-by=/etc/apt/keyrings/fpgas-online-fpga-tools.gpg] \
  https://fpgas-online.github.io/fpgas.online-fpga-tools/$(. /etc/os-release; echo $VERSION_CODENAME)/ ./" \
  | sudo tee /etc/apt/sources.list.d/fpgas-online-fpga-tools.list
sudo apt update
sudo apt install openfpgaloader-fpgasonline openocd-fpgasonline

Suites: bookworm, trixie, sid. Static binaries for arm64, armv7 and armv6 are on the GitHub Releases page.
