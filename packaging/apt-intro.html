openFPGALoader and OpenOCD carrying the fpgas.online patch series: Raspberry Pi 5 RP1 PIO JTAG, Kosagi NeTV2 configurations, the Tiny Tapeout FPGA Demo Board, SPI flash identification and Device DNA / ECP5 TraceID reads. arm64 and armhf.

openfpgaloader-fpgasonline-gitmasteropenFPGALoader git master + patches
openocd-fpgasonlinestablelatest OpenOCD release + patches
openocd-fpgasonline-gitmasterOpenOCD git master + patches

Each package replaces Debian's openfpgaloader / openocd (and the older *-rp1pio packages) in place. Versions read <upstream>+fpgasonline.<patchset>, e.g. 1.1.1+fpgasonline.0.0.post12, or <upstream>+git<date>.<sha>+fpgasonline.<patchset> for the git track. Static binaries for arm64, armv7 and armv6 are on the GitHub Releases page.
